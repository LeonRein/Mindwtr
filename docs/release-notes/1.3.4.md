# Mindwtr 1.3.4

Mindwtr 1.3.4 adds built-in desktop MCP access, more ways to organize projects and tasks, optional archive retention, and safer calendars, reminders, attachments, and sync.

## Highlights

- Connect an AI client through Settings → Integrations → MCP on desktop, with no separate runtime installation. Access is disabled and read-only by default.
- Organize Someday projects inside sections, convert simple projects into sections, and move selected tasks with the unified Destination control.
- Choose whether future start dates appear in Today, and optionally expire archived work after a confirmed retention period. Archive retention defaults to Never.
- See timed deadlines in Day and Week calendars, including date-less daily and weekly repeats, with safer calendar creation, color changes, and deletion.
- Open UpNote links from notes and attachments, link desktop folders, and copy selected task titles.
- Android adds an Add task… launcher shortcut for detailed capture; reminders, widget links, and queued check-offs recover more reliably.
- iOS widgets show task contexts, audio capture preserves keyboard focus, and mobile project and Inbox editing stay responsive.
- Sync protects attachment edits and partly encrypted folders, improves CloudKit upload retries, redacts credentials, and fixes Windows File Sync attachment uploads.

## Tasks, projects, Focus, and review

- Someday projects appear within their chosen sections, section counts include projects, and project section assignments sync across devices.
- Simple projects can become sections with checked task transfers; mobile projects can move up or down within their Area.
- Today has an optional start-date inclusion preference. Focus stars sit beside the mobile title, and Waiting For names stand out in task rows.
- Tasks indicate that they have a description when row details are hidden.
- Bulk organization uses Destination for Project, Area, or None and preserves task selection through the move.
- Inbox Incubate requires a review date; context/tag headings and Chinese Incubate and Review wording are clearer.
- Search shorthand follows field filters, search results open the task's final view, and monthly weekday recurrence keeps its custom setting.
- Mobile Projects no longer freezes after adding a task on iOS, the project tag picker's + adds without toggling, and Process Inbox recovers its opacity after opening Description.

## Archive and data lifecycle

- Optional Archive retention permanently removes eligible archived tasks and projects after a positive whole number of days; Never remains the default.
- Enabling or shortening retention requires confirmation. Newly dated legacy records receive a full period; active projects, newer contents, and concurrent edits protect work from early cleanup.
- Retention settings and deletion markers sync; backups and provider history remain separate from current-library cleanup.
- SQLite and shared canonical writes preserve untouched records and newer attachment metadata during editor saves, recovery, and concurrent changes.

## Calendars and reminders

- Timed deadlines render as markers in Day and Week, while date-only deadlines remain all-day.
- Daily and weekly recurring tasks without an initial date appear in Calendar.
- Subscribed desktop calendars load without an Origin header, and subscription displays hide embedded credentials.
- Calendar Test reports load failures; refreshes are throttled, and choosing the current color avoids unnecessary writes.
- Creating, recoloring, and deleting the app's calendar retain ownership and recovery evidence; provider failures preserve saved IDs and pushed events. Calendar settings explain what deletion keeps.
- Android reminder reschedules serialize, stale one-shot reminders do not resurface, withdrawn delivered reminders leave the tray, and permission-denied resume cleans up alarms.
- Done and Snooze actions settle durably; notification opening and Pomodoro behavior use the shared reminder policy.

## Capture, widgets, links, and attachments

- Android distinguishes quick Capture from Add task… detailed capture in launcher shortcuts and keeps capture-screen buttons above the keyboard.
- Audio capture startup retains keyboard focus; Siri recognizes the spoken Mind Water name.
- iOS home-screen widgets show task contexts. Mobile widget task links resolve from the startup snapshot.
- Widget publication retries failed disk commits, and queued captures/check-offs settle all items, preserve durable command history, and avoid reapplying failed records.
- UpNote links open from Markdown, checklist references, and link attachments with copy-link recovery when the handoff fails.
- Desktop tasks and projects can link folders; selected task titles can be copied together, and the saved global quick-add shortcut survives startup.
- Editor saves preserve attachment changes made by sync while the editor is open. Cleanup checks current file ownership immediately before deletion.
- Opening a local project attachment avoids rewriting the project; missing remote files become unrecoverable consistently across WebDAV, Dropbox, and self-hosted Cloud.
- Attachment hashing can stream through capable native hosts, and interrupted installer recovery retains recorded ownership.

## Sync, encryption, and privacy

- Windows File Sync compares attachment publication roots using Windows path semantics.
- Manual Sync with unchanged mobile settings runs a normal cycle rather than repeating backend activation.
- CloudKit uploads use smaller batches, retry server-requested waits within a bound, skip redundant lookups for newly empty record types, and report the failing step.
- Redirected writes cannot count as successful uploads; streamed attachment uploads verify publication before recording it and recover from unprovable HEAD responses.
- Partly encrypted sync locations refuse plaintext attachment uploads. Encryption setup can be abandoned on this device, with the warning scoped to its location.
- WebDAV encryption refuses incompatible servers without strong ETags before mutation begins.
- Sync and AI errors redact credentials even when an endpoint changes during a request. AI provider model discovery waits for consent, cancelled requests release their slot, and review suggestions reject tasks changed since analysis.
- Diagnostics preserve unreadable logs, bound trimming failures, and keep release confirmations available to field testers without logging task text or secrets.

## Desktop, MCP, and distribution

- Desktop bundles a managed, authenticated loopback MCP helper with enable, Allow changes, Retry, copy-connection, and token rotation controls. Built-in MCP requires macOS 13 or later on Mac.
- The independent mindwtr-mcp package adds an optional desktop Local API backend, with explicit token authentication, read-only defaults, restricted tool coverage, and no fallback to direct database access.
- macOS recovers windows after renderer termination; Flatpak asks the Secret portal once per launch and drops superseded hotfix patches during release updates.
- Dependency security updates, Windows MCP compiler/cache handling, Apple output cleanup, native platform checks, and release governance receive targeted fixes.
- Sponsor acknowledgments and repository documentation are updated.

## Native mobile development ports

- The isolated Android Compose and iOS SwiftUI development clients gain shared-core parity; stable mobile releases continue to ship the production React Native app.
- Both ports expand durable request receipts, ordered write journals, replay validation, conflict handling, diagnostics, settings, and cold-start recovery.
- Android adds shared sync/encryption, AI actions, task/project attachments, Project Details, background CoreWork jobs, reminder ownership, and widget publication, with upgrade and device harnesses. QuickJS bytecode caching, parallel startup work, deferred reads, and explicit startup budgets reduce boot work.
- iOS adds Focus grouping/filter/order, History/Reference sorting and folds, Someday sections, Board picker search, Manage metadata, settings and editor layout, saved searches, task/project lifecycle actions, completion undo/backdating, and bulk actions with exact recovery.
- iOS also adds backup/export/import and undo for Mindwtr JSON/CSV/ZIP, TaskNotes, Todoist, TickTick, OmniFocus, and DGT GTD; confined diagnostics and attachment file hosts; durable attachment drafts, publication, checkpoint saves, and retirement jobs.
- Native layout, large-text accessibility, row identity, picker delays, process-death recovery, RN migration boundaries, and parity evidence receive expanded checks. These development-port checks do not establish production paired-Watch or reporter acceptance.
